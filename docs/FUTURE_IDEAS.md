# Future Ideas and Deferred Scope

## Entry rule

An idea may enter active work only when it earns a rubric item, passes a Critical Gate, or fixes a verified defect blocking the active release. Otherwise, it remains deferred here; this file does not create an implementation schedule.

## Explicitly deferred

- Automatically commenting on or modifying third-party GitHub repositories
- Autonomous code changes, fixes, or pull requests
- Kubernetes and Helm
- MCP server or client implementation
- Mobile or native desktop applications
- Training or fine-tuning a foundation model
- Multiple paid commercial AI subscriptions
- Enterprise SSO/SAML
- Billing and subscriptions
- Real-time collaboration
- Large-scale load testing beyond a small documented baseline
- Extensive animation, perfect visual design, or visual-polish work
